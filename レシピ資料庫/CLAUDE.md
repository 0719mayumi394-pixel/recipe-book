# まゆのレシピ資料庫

## 概要
- 目的：作ったことのある・作ってみたいレシピを整理・保存する個人レシピ資料庫
- 担当者：まゆ

## カテゴリ一覧
- 01_和食　　　　　　　煮物・炒め物・汁物・和え物など
- 02_洋食　　　　　　　パスタ・グラタン・スープ・肉料理など
- 03_中華・アジアン・せいろ料理　　中華・韓国・エスニック・蒸し料理など
- 04_パン・お菓子　　　手作りパン・ケーキ・クッキー・和菓子など
- 05_作り置き・常備菜　まとめて作れるおかず・漬物・ソースなど
- 06_アーカイブ　　　　古いレシピ・しばらく作らないレシピの保管場所

## ディレクトリ構造
- 00_新着・未分類/          迷ったらここ。後で適切なフォルダへ移動する
- 01_和食/
- 02_洋食/
- 03_中華・アジアン・せいろ料理/
- 04_パン・お菓子/
- 05_作り置き・常備菜/
- 06_アーカイブ/

## 運用ルール
- 新しいレシピはまず「00_新着・未分類」に保存してOK。後でゆっくり整理する
- レシピのファイル名は「料理名.md」が基本（例：肉じゃが.md、食パン.md）
- PDFやメモも「00_新着・未分類」に入れておけば迷子にならない
- 作ってみて気に入ったレシピには ⭐ をファイル名の先頭につける（例：⭐食パン.md）

## ⚙️ Claudeへの作業手順（レシピを追加・変更するとき）

### 新しいレシピを保存するとき
1. **カテゴリフォルダを判断する**（迷ったら `00_新着・未分類/` でOK）
2. **MDファイルを作成する**（`料理名.md`）→ 下記テンプレートに従う
3. **HTMLファイルを作成する**（`料理名.html`）→ 既存の `包まない小籠包.html` と同じスタイルで作る
4. **`index.html` を更新する**
   - 該当カテゴリのレシピグリッドに `<a class="recipe-card ...">` カードを追加する
   - 該当カテゴリの `<span class="category__count">` の数字を +1 する
   - ヒーローの「全 〇 レシピ」の数字を +1 する

### レシピの内容を変更するとき
- `料理名.md` と `料理名.html` の**両方**を同じ内容に修正する

### index.html のレシピカード記述例
```html
<a class="recipe-card category--chuka" href="03_中華・アジアン・せいろ料理/料理名.html">
  <div class="recipe-card__top">
    <div class="recipe-card__dot"></div>
    <span class="recipe-card__tag">中華・アジアン</span>
  </div>
  <p class="recipe-card__name">料理名</p>
  <p class="recipe-card__meta">
    <span class="material-icons">schedule</span>約〇分
    <span style="margin-left:0.4rem"><span class="material-icons">group</span>〇人分</span>
  </p>
</a>
```

カテゴリクラス対応表：
- 和食 → `category--washoku`
- 洋食 → `category--yoshoku`
- 中華・アジアン・せいろ料理 → `category--chuka`
- パン・お菓子 → `category--pan`
- 作り置き・常備菜 → `category--tsukuri`
