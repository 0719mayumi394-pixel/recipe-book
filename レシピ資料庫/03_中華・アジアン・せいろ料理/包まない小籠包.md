# 包まない小籠包 🐷🥟

> おうちで簡単に作れる！

- **人数**：2人分（ココットS 5個分）
- **時間**：約15分
- **カテゴリ**：中華・アジアン・せいろ料理

---

## 材料

### メイン
| 材料 | 分量 |
|------|------|
| 豚ひき肉 | 200gくらい |
| 玉ねぎ | 1/2個 |
| 餃子の皮 | 5枚 |

### ◎調味料
| 材料 | 分量 |
|------|------|
| 砂糖 | 小さじ1 |
| 鶏ガラ | 小さじ1 |
| 醤油 | 小さじ1 |
| 酒 | 小さじ1 |
| ごま油 | 小さじ1 |
| オイスターソース | 小さじ1 |
| 生姜すりおろし | 小さじ1（生姜チューブでもok） |
| 水 | 100ml |

### トッピング
- 小口ネギ
- 生姜（細い千切り）
- 白ゴマ

---

## 作り方

1. ひき肉、みじん切りにした玉ねぎ、◎を入れて混ぜる
2. 薄くごま油を塗った耐熱容器に均等に入れたら、濡れた餃子の皮を乗せる
3. せいろで10〜15分蒸す
4. お好みのトッピングをしたら完成

---

## メモ・コツ
- 1の材料と調味料を混ぜるとき、ナイロン袋などに入れて混ぜると洗い物が減る
- 2の餃子の皮は上だけでなく下にも敷いてもいい
