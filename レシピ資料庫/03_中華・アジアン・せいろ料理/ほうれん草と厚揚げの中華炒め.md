# ほうれん草と厚揚げの中華炒め

- **人数**：2〜3人分
- **時間**：約20分
- **カテゴリ**：中華・アジアン・せいろ料理

---

## 材料

### メイン
| 材料 | 分量 |
|------|------|
| ほうれん草 | 1束（200g） |
| 厚揚げ | 1枚（270g） |
| 豚ひき肉 | 150g |
| ごま油 | 大さじ1/2 |

### A（香味）
| 材料 | 分量 |
|------|------|
| 長ネギ（みじん切り） | 20cm |
| ニンニク（みじん切り） | 1かけ |
| ショウガ（みじん切り） | 1かけ |
| 豆板醤 | 小さじ1/2〜 |

### B（調味料）
| 材料 | 分量 |
|------|------|
| みりん | 大さじ1と1/2 |
| 酒 | 大さじ1と1/2 |
| みそ | 大さじ1と1/2 |
| オイスターソース | 大さじ1と1/2 |

---

## 作り方

1. 鍋に湯を沸かしてほうれん草を1分ゆで、冷水に取って水気をきり、4cm長さに切ってしっかりと絞る
2. 厚揚げは大きめに手でちぎって耐熱容器に入れ、ラップをして電子レンジ（600W）で2分加熱する
3. フライパンにごま油をひき、Aの長ネギ・ニンニク・ショウガ・豆板醤を入れて香りが立つまで炒める
4. ひき肉を入れてさらに炒める
5. 肉に火がとおったら、Bのみりん・酒・みそ・オイスターソースを加え、軽く炒め合わせる
6. ②の厚揚げ、①のほうれん草を加えてさっと炒める

---

## メモ・コツ
- 厚揚げは大きめに手でちぎることで味が染みやすくなる
