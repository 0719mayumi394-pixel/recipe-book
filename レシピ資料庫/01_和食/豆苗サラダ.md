# 豆苗サラダ

- **人数**：2〜3人分
- **時間**：約10分
- **カテゴリ**：和食

---

## 材料

### メイン
| 材料 | 分量 |
|------|------|
| 豆苗 | 1パック |
| 玉ねぎ（スライス） | 少し |
| ツナ缶 | 1缶 |

### ◎調味料
| 材料 | 分量 |
|------|------|
| 砂糖 | 小さじ1 |
| 鶏がらスープ素 | 小さじ1 |
| 醤油 | 小さじ1 |
| 酢 | 小さじ1 |
| ごま油 | 小さじ1 |

---

## 作り方

1. 豆苗は洗って食べやすい大きさに切る。玉ねぎはスライスする
2. 砂糖・鶏がらスープ素を合わせてよく混ぜる
3. 醤油・酢・ごま油を加えてさらに混ぜる
4. ツナ缶を汁ごと加えて全体をよく混ぜたら完成

---

## メモ・コツ
- 調味料を先に混ぜてから野菜と合わせると味がなじみやすい
- 豆苗は根元を切り落とし、半分くらいの長さに切ると食べやすい
